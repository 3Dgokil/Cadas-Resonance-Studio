# Cadas Resonance Studio

AI-assisted YouTube Shorts production studio.

## Features

- Indonesian horror-comedy mode
- Global 3D skeleton comedy mode
- Smart CTA controls
- Google Flow video prompt generation
- Integrated B-roll planning
- JSON export
- ClarioHub API integration

## Setup

1. Install dependencies:

   pip install -r requirements.txt

2. Configure CLARIOHUB_API_KEY as an environment variable.

3. Run:

   streamlit run app.py
